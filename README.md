# aiagentworx-site

Marketing website for **AI Agent Worx** — [aiagentworx.ai](https://aiagentworx.ai)

Built with [Astro](https://astro.build) and deployed on [Cloudflare Pages](https://pages.cloudflare.com).

## Develop

```sh
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

```sh
npm run build
```

Output goes to `./dist/`.

## Deploy

This repo is connected to Cloudflare Pages. Pushes to `main` deploy automatically.

**Build settings (Cloudflare Pages):**
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
